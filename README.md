# EcoPathFinder_Final_Project
Vision-Based Machine Learning Assistant with IoT-Integrated GIS for Sustainable Development
EcoPathFinder is an AI-powered environmental decision-support system that combines IoT sensing, computer vision, machine learning, and GIS analytics to help planners identify infrastructure routes with the lowest ecological impact.

The platform integrates real-time environmental sensor data, satellite imagery, and geospatial analysis to predict deforestation risk, estimate carbon stock loss, compare project alignments, and translate environmental impact into financial metrics.

📌 Problem Statement

Conventional Environmental Impact Assessments (EIAs) often:

Depend on static surveys and periodic reports
Lack real-time environmental monitoring
Provide limited predictive capabilities
Do not quantify ecological losses in financial terms
Offer limited scenario-based route comparison

EcoPathFinder addresses these challenges through a unified AI + IoT + GIS framework.

🚀 Key Features
🌍 Real-Time IoT Monitoring

Collects environmental data from field sensors:

CO₂ concentration
Air quality
Temperature
Humidity
Soil moisture
Biodiversity indicators

Uses geospatial datasets from platforms such as:

Sentinel-1
Sentinel-2
SMAP
Landsat

🤖 AI-Powered Environmental Prediction

Machine learning models analyze:

Deforestation probability
Vegetation stress
Carbon stock loss
Habitat fragmentation risk

Carbon impact
